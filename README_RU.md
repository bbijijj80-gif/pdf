# HP LaserJet Scanner для Windows

Программа для сканирования документов с принтеров HP LaserJet со встроенным сканером.
Работает **только на Windows** (10/11) через нативный API WIA (Windows Image Acquisition).

## ⚠️ Важные требования

### 1. Операционная система
- **Только Windows 10/11** (использует WIA - Windows Image Acquisition)
- Не работает на Linux, macOS или через WSL

### 2. Драйверы
Убедитесь, что установлены драйверы для вашего сканера HP:
- Скачайте с [hp.com/support](https://support.hp.com)
- Должны быть установлены драйверы **WIA** или **TWAIN**
- Проверьте в "Устройства и принтеры" что сканер отображается

### 3. Сетевое подключение
Для сетевых сканеров:
- Сканер должен быть доступен по сети
- IP-адрес должен быть прописан в драйверах Windows
- Брандмауэр не должен блокировать WIA

```bash

```

## 🔧 Возможности

### Многостраничное сканирование
1. Нажмите **"📄 Сканировать страницу"**
2. Положите первую страницу в сканер
3. После сканирования положите следующую
4. Нажмите **"📄 Сканировать страницу"** снова
5. Повторяйте пока все страницы не будут отсканированы
6. Нажмите **"✅ Завершить и редактировать"**

### Редактирование порядка страниц
- **◀ Переместить влево** - сдвинуть выбранную страницу влево
- **Переместить вправо ▶** - сдвинуть выбранную страницу вправо
- **✕ Удалить выбранную** - удалить ненужную страницу
- Клик по превью выбирает страницу
- Горячие клавиши: ← → Delete

### Настройки сканирования
- **Цвет**: Color / Grayscale / BlackAndWhite
- **DPI**: 150 / 200 / 300 / 400 / 600
- **Формат**: A4 / A3 / Letter / Legal
- **Сохранять отдельно**: каждый файл отдельно или один PDF

### Сохранение
- Объединённый PDF со всеми страницами в заданном порядке
- Или отдельные PDF файлы для каждой страницы
- Автоматическое масштабирование под размер страницы

## 🐛 Решение проблем

### "Сканер не найден"
1. Проверьте подключение сканера (USB или сеть)
2. Установите драйверы с hp.com/support
3. Перезапустите службу WIA:
   ```
   net stop stisvc
   net start stisvc
   ```
4. Проверьте в "Устройства и принтеры" что сканер виден

### "Белый экран при сканировании"
1. Убедитесь что документ лежит правильно
2. Проверьте что сканер открыт (крышка закрыта)
3. Попробуйте другое значение DPI (300 вместо 600)

### "No job URL returned" / "Не удаётся найти указанный путь"
Это ошибка сетевого подключения:
1. Проверьте IP-адрес сканера в настройках Windows
2. Пингуйте сканер: `ping 192.168.1.xxx`
3. Переустановите драйверы с правильным IP
4. Для USB подключений - переподключите кабель

### Программа зависает на "Начало сканирования"
1. Закройте программу через диспетчер задач
2. Перезагрузите компьютер
3. Обновите драйверы сканера
4. Попробуйте меньшее значение DPI

### Ошибка comtypes / WIA
```bash
# Переустановка comtypes
pip uninstall comtypes
pip install comtypes

# Проверка WIA службы
services.msc  # найдите "Служба загрузки изображений Windows"
```

## 📝 Примечания

- Программа использует **WIA** (Windows Image Acquisition) - стандартный API Windows
- Не требует SANE, pyinsane2 или других Linux-библиотек
- Все операции сканирования выполняются в отдельном потоке (не блокирует интерфейс)
- При ошибках окно не закрывается - можно прочитать сообщение об ошибке
- Терминал остаётся открытым для просмотра логов

## 🆘 Если ничего не помогает

1. Откройте терминал (командную строку)
2. Запустите: `python scanner_app.py`
3. Посмотрите текст ошибки в терминале
4. Проверьте:
   - Драйверы установлены?
   - Сканер виден в Windows?
   - Сканер готов (нет ошибок на дисплее)?
   - Документ лежит правильно?
