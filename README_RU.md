# HP LaserJet MFP Scanner for Windows

## Описание
Программа для сканирования документов с принтера HP LaserJet MFP M28w через TWAIN интерфейс.

## Требования
- Windows 10/11 (также работает на Windows 9)
- Python 3.8 или выше
- HP LaserJet M28w с установленными драйверами

## Установка

### Шаг 1: Установите драйверы HP
1. Скачайте полные драйверы с официального сайта HP:
   https://support.hp.com/drivers
2. Найдите вашу модель: HP LaserJet MFP M28w
3. Установите **Full Feature Drivers** (обязательно должен быть TWAIN драйвер)
4. Подключите принтер по USB или настройте сетевое подключение

### Шаг 2: Установите зависимости Python
Запустите файл установки:
```
install_drivers.bat
```

Или вручную:
```bash
pip install python-twain Pillow PyPDF2
```

## Использование

### Запуск программы
Дважды кликните на `run_scanner.bat` или выполните в командной строке:
```bash
python scanner.py
```

### Процесс сканирования

1. **Выберите сканер** из выпадающего списка (ваш HP LaserJet M28w должен отображаться)
2. **Настройте параметры**:
   - Цветовой режим: Color / Grayscale / Black & White
   - Разрешение: 150/200/300/600 DPI

3. **Сканирование нескольких страниц**:
   - Нажмите "📷 Scan Page"
   - Положите первую страницу в сканер
   - Дождитесь окончания сканирования
   - Положите следующую страницу
   - Снова нажмите "📷 Scan Page"
   - Повторяйте пока не отсканируете все страницы

4. **Редактирование порядка**:
   - Перетаскивайте миниатюры горизонтально для изменения порядка страниц
   - Кнопка "🗑" на миниатюре удаляет конкретную страницу
   - Кнопка "🗑 Clear All" очищает все отсканированные страницы

5. **Сохранение**:
   - Нажмите "✓ Finish & Edit"
   - Выберите место сохранения PDF файла
   - Все страницы сохранятся в одном PDF файле в указанном порядке

## Решение проблем

### "No scanners found" / "Нет сканеров"
- Убедитесь, что принтер включён
- Проверьте подключение (USB или сеть)
- Переустановите драйверы HP с полным пакетом функций
- Перезагрузите компьютер

### "Scanner device error"
- Проверьте, есть ли бумага в сканере
- Убедитесь, что крышка сканера закрыта
- Перезапустите программу

### Белый экран при сканировании
- Обновите драйверы TWAIN с сайта HP
- Попробуйте другое разрешение (200 или 150 DPI)
- Используйте USB подключение вместо сетевого

### Программа зависает при сканировании
- Закройте другие программы, использующие сканер
- Перезагрузите принтер
- Проверьте антивирус (может блокировать доступ к сканеру)

## Технические детали

- Использует TWAIN интерфейс для совместимости со всеми сканерами
- Не требует Linux подсистем (SANE, WSL и т.д.)
- Работает напрямую с драйверами Windows
- Создаёт PDF через библиотеку Pillow
- Поддерживает многопоточное сканирование без зависания интерфейса
