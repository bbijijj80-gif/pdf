# HP LaserJet Network Scanner для Windows

Программа для сканирования документов с принтеров HP LaserJet со встроенным сканером через сеть.

## Требования

- Windows 10/11
- Python 3.8 или выше
- Установленные драйверы TWAIN или WIA для вашего сканера HP

## Установка

### 1. Установите Python
Скачайте и установите Python с официального сайта: https://www.python.org/downloads/

### 2. Установите зависимости
Откройте командную строку (cmd) от имени администратора и выполните:

```bash
pip install Pillow pyinsane2
```

### 3. Установите драйверы сканера
Убедитесь, что установлены драйверы для вашего сканера HP:
- Скачайте с официального сайта HP: https://support.hp.com
- Или используйте диск из комплекта поставки

## Запуск программы

```bash
python scanner_app.py
```

## Использование

1. **Выбор сканера**: Выберите ваш сканер HP из списка в верхней панели
2. **Настройки**: Настройте параметры сканирования:
   - Цветовой режим (Color, Grayscale, Black & White)
   - Разрешение (DPI)
   - Формат бумаги

3. **Многостраничное сканирование**:
   - Нажмите "📄 Сканировать страницу"
   - Положите первую страницу и нажмите кнопку сканирования
   - После сканирования положите следующую страницу
   - Снова нажмите "📄 Сканировать страницу"
   - Повторяйте пока не отсканируете все страницы
   - Нажмите "✓ Завершить сканирование"

4. **Редактирование страниц**:
   - Используйте кнопки ◀ ▶ для перемещения страниц
   - Кнопка ✕ удаляет страницу
   - Страницы отображаются горизонтально с прокруткой

5. **Сохранение**:
   - "💾 Сохранить как отдельный PDF" - каждая страница в отдельном файле
   - "📚 Сохранить объединённый PDF" - все страницы в одном файле

## Особенности

- ✅ Сканирование по сети
- ✅ Многостраничное сканирование без объединения
- ✅ Редактирование порядка страниц
- ✅ Выбор цветового режима
- ✅ Сохранение в PDF
- ✅ Отображение ошибок без закрытия программы
- ✅ Потоковое сканирование (не блокирует интерфейс)

## Решение проблем

### Ошибка "Нет доступных сканеров"
- Убедитесь, что сканер включен и подключен к сети
- Проверьте, установлены ли драйверы TWAIN/WIA
- Нажмите кнопку "Обновить" для повторного поиска

### Белый экран при сканировании
- Проверьте настройки цветового режима
- Попробуйте изменить DPI
- Перезапустите программу и сканер

### Ошибка соединения
- Проверьте IP-адрес сканера
- Убедитесь, что компьютер и сканер в одной сети
- Проверьте брандмауэр Windows

## Примечания

- Программа работает только на Windows (не использует SANE/Linux)
- Требуется установленный драйвер сканера
- Для сетевых сканеров может потребоваться настройка IP-адреса
