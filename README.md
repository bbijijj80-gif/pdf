# HP LaserJet Scanner для Windows

Программа для сканирования документов с принтеров HP LaserJet через сеть с сохранением в PDF.

## Требования

- Windows 10/11 (использует WIA - Windows Image Acquisition)
- Python 3.8 или выше
- Установленные драйверы для вашего сканера HP LaserJet

## Установка зависимостей

```bash
pip install pywin32 Pillow
```

**Важно:** Программа использует нативный Windows API (WIA), поэтому:
- НЕ требует SANE или каких-либо подсистем Linux
- НЕ требует pyinsane2
- Работает только на Windows

## Запуск

```bash
python scanner.py
```

## Возможности

1. **Выбор сканера из списка** - автоматически обнаруживает все доступные сканеры в системе
2. **Многостраничное сканирование** - сканируйте страницы по одной, нажимая "Scan Page"
3. **Перетаскивание страниц** - меняйте порядок страниц горизонтально перед сохранением
4. **Выбор цвета** - Цвет, Оттенки серого, Чёрно-белый
5. **Сохранение в PDF** - все страницы сохраняются в одном PDF файле в выбранном порядке
6. **Обработка ошибок** - при ошибке сканирования программа не закрывается, показывается подробное сообщение

## Как использовать

1. Запустите программу
2. Выберите сканер из выпадающего списка (если их несколько)
3. Выберите режим цвета (Цвет/Оттенки серого/Чёрно-белый)
4. Нажмите "Scan Page" для сканирования первой страницы
5. Положите следующую страницу и нажмите "Scan Page" снова
6. Повторяйте пока все страницы не будут отсканированы
7. При необходимости перетащите страницы мышкой для изменения порядка
8. Нажмите "Finish & Save" для сохранения в PDF
9. Выберите место сохранения и имя файла

## Решение проблем

### "No scanners found" / "Сканеры не найдены"
- Убедитесь, что сканер включён и подключён к сети
- Проверьте, что установлены драйверы HP для вашей модели
- Попробуйте просканировать через стандартное приложение Windows "Факсы и сканирование"

### Ошибка сканирования
- Проверьте подключение к сети
- Перезагрузите сканер
- Убедитесь, что крышка сканера закрыта
- Проверьте, нет ли замятия бумаги

### Белый экран вместо скана
- Обычно означает проблему с драйверами
- Переустановите драйверы HP с официального сайта
- Попробуйте подключить сканер через USB для проверки

## Примечания

- Программа работает только на Windows (использует WIA API)
- Для сетевых сканеров убедитесь, что они доступны в системе Windows
- Все отсканированные изображения хранятся в памяти до сохранения PDF
