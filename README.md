# HP LaserJet MFP Scanner

Программа для сканирования документов через HP LaserJet MFP M28w и другие сканеры в Windows.

## Особенности

- ✅ Работает на Windows 10/11 без Linux подсистем
- ✅ Использует нативный WIA (Windows Image Acquisition)
- ✅ Выбор сканера из списка доступных устройств
- ✅ Сканирование нескольких страниц по одной
- ✅ Горизонтальная прокрутка отсканированных страниц
- ✅ Перетаскивание страниц местами (кнопки ◀ ▶)
- ✅ Удаление отдельных страниц
- ✅ Сохранение в PDF, PNG или JPG
- ✅ Настройки: цвет/чб, DPI, формат
- ✅ При ошибке окно не закрывается - видно ошибку

## Требования

- Windows 10/11
- Python 3.8 или выше
- Драйверы HP LaserJet установлены

## Установка

1. **Запустите установщик зависимостей:**
   ```
   install_dependencies.bat
   ```
   
   Или вручную установите пакеты:
   ```
   pip install comtypes Pillow
   ```

2. **Запустите программу:**
   ```
   python scanner.py
   ```

## Использование

1. **Выберите сканер** из выпадающего списка (ваш HP LaserJet MFP M28w должен появиться автоматически)
2. **Настройте параметры:**
   - Цвет: цветное / оттенки серого / ч/б
   - DPI: 150-600
   - Формат: PDF / PNG / JPG
3. **Нажмите "📷 Сканировать страницу"**
4. **Положите следующую страницу** и снова нажмите "Сканировать" (или сразу завершите)
5. **Перетащите страницы местами** кнопками ◀ ▶ если нужно изменить порядок
6. **Нажмите "✅ Завершить и сохранить"**
7. **Выберите место сохранения** файла

## Решение проблем

### Сканер не найден
- Убедитесь что принтер включен и подключен к сети
- Проверьте что драйверы HP установлены
- Нажмите "Обновить" список сканеров
- IP вашего устройства: 192.168.0.145

### Белый экран при сканировании
- Попробуйте другое разрешение (DPI)
- Переустановите драйверы HP с официального сайта
- Проверьте что сканер открыт и готов

### Ошибка "no job url returned"
- Эта ошибка была в старой версии с pyinsane2
- Новая версия использует WIA и этой ошибки нет

### comtypes не установлен
- Запустите `install_dependencies.bat`
- Или: `pip install comtypes`

## Техническая информация

Программа использует:
- **WIA (Windows Image Acquisition)** - стандартный интерфейс Windows для сканеров
- **comtypes** - библиотека для работы с COM-объектами Windows
- **Pillow** - обработка и сохранение изображений
- **tkinter** - графический интерфейс

Никаких Linux подсистем (WSL), SANE или pyinsane2 - только нативные Windows API!
